# Convergence Microscope

Routing verifiers check a network before and after a change. This project shows what happens in between, packet by packet.

Status: under construction. This README lists only what is implemented and tested; see `reports/` for per-phase status.

## Scope and limits

- Everything runs as containers on one VM.
- There are no switch ASICs.
- Timings are lab timings, not hardware timings.

Independent portfolio project, not affiliated with Meta.
